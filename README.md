CAPFUN CHECK IN — PAGE DE PRÉSENTATION

Contenu :
- index.html : page publique de présentation
- qr-capfun-check-in.png : QR code pointant vers la démo V2

Pour mettre en ligne avec GitHub Pages :
1. Créer un dépôt PUBLIC distinct, par exemple capfun-check-in-presentation.
2. Ajouter index.html et qr-capfun-check-in.png à la racine du dépôt.
3. Ouvrir Settings > Pages > Build and deployment.
4. Choisir Deploy from a branch, puis main et /(root), enregistrer.
5. Attendre la publication ; l'adresse sera généralement :
   https://VOTRE-PSEUDO.github.io/capfun-check-in-presentation/

Le lien de l'application V2 est déjà intégré aux boutons et au QR code.
ATTENTION : la page de présentation est publique, mais l'application de test doit rester protégée contre l'accès non autorisé aux fonctions de réception et aux données. N'utiliser que des données fictives tant que la sécurité et la conformité ne sont pas validées.
